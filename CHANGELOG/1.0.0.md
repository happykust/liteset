# Liteset 1.0.0 (2026-06-18)

First public release: a drop-in async backend for **Apache Superset 6.0.0**. Stop
Superset, start Liteset on the same metadata database, and keep working with the
same dashboards, datasets, users and roles — only the web layer becomes async.

### Added
- Litestar/ASGI web layer on Uvicorn + uvloop, replacing Flask/WSGI + Gunicorn.
- Fully async data access: SQLAlchemy 2.0 `AsyncSession` + asyncpg/aiosqlite across
  all DAOs; sync engine specs bridged via a `run_sync` fallback for non-async drivers.
- `msgspec`-based DTOs and validation (replaces Marshmallow and Pydantic v1).
- Native Litestar WebSocket for Global Async Queries (replaces the standalone
  Node.js `superset-websocket` service); polling REST transport also supported.
- `pydantic-settings` configuration with backward compatibility for
  `superset_config.py` and the legacy `SUPERSET_*` environment variables.
- Async security manager (RBAC, RLS, guest tokens, OAuth/OIDC/LDAP login) and an
  ASGI middleware stack (auth, CSRF, ProxyFix, rate-limit, security headers, locale).
- CI/CD on GitHub Actions: lint/pre-commit, Python unit + Postgres integration
  tests, frontend, Cypress e2e, Docker → GHCR, docs + Helm → GitHub Pages, and
  Python publishing to PyPI via OIDC Trusted Publishing.

### Changed
- All ORM models use SQLAlchemy 2.0 typed `Mapped[]` annotations; the codebase is
  `mypy`-clean (0 errors across the package).
- Alembic migrations run on psycopg2 (sync); the application runtime uses asyncpg.
- Celery tasks are retained unchanged (orthogonal to the HTTP layer).

### Removed
- The Flask/WSGI stack and the standalone Node.js WebSocket sidecar.

### Compatibility
- Python 3.11–3.12.
- The metadata DB schema, REST API, WebSocket contract and SPA frontend are
  inherited 1:1 from Apache Superset 6.0.0.

# Исправленные CVE по релизам

:::info Liteset наследует все upstream-фиксы
Список CVE ниже — **исторический реестр** advisory Apache Superset. Liteset 6.0.0 основан на Apache Superset 6.0.0 и содержит все исправления для версий ≤ 6.0.0 — эти CVE **не затрагивают** Liteset.

Для уязвимостей, специфичных для Liteset (в async-runtime, AsyncSecurityManager, кастомных middleware) — см. [GitHub Security Advisories проекта](https://github.com/happykust/liteset/security/advisories) и [процесс репортинга](/docs/contributing/misc#reporting-a-security-vulnerability).

Если вы нашли уязвимость в коде upstream Apache Superset, который Liteset переиспользует (фронтенд, движок чартов, SQL-парсер, FAB-производная auth-логика) — сообщите в Apache через [`private@superset.apache.org`](https://superset.apache.org/docs/security/security#reporting-security-vulnerabilities) — Liteset подтянет фикс на следующем синке.
:::

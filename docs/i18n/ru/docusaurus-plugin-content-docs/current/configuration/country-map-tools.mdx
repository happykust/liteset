# Визуализация Country Map

Country Map позволяет рисовать лёгкие хороплет-карты стран по областям, штатам и другим подразделениям. Не требует сторонних map-сервисов, но требует от вас [ISO-3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) кодов верхнеуровневых подразделений страны. Коды ISO менее неоднозначны, чем полные имена регионов, и уникальны во всём мире.

## Включённые карты

Текущий список стран — в исходниках [legacy-plugin-chart-country-map/src/countries.ts](https://github.com/happykust/liteset/blob/main/superset-frontend/plugins/legacy-plugin-chart-country-map/src/countries.ts).

Country Map уже идёт с картами следующих стран:

<ul style={{columns: 3}}>
{countriesData.countries.map((country, index) => (
  <li key={index}>{country}</li>
))}
</ul>

## Добавление новой страны

Чтобы добавить страну, нужно отредактировать файлы в [@superset-ui/legacy-plugin-chart-country-map](https://github.com/happykust/liteset/tree/main/superset-frontend/plugins/legacy-plugin-chart-country-map):

1. Сгенерируйте GeoJSON для страны по [этому Jupyter-ноутбуку](https://github.com/happykust/liteset/blob/main/superset-frontend/plugins/legacy-plugin-chart-country-map/scripts/Country%20Map%20GeoJSON%20Generator.ipynb).
2. Отредактируйте список стран в [legacy-plugin-chart-country-map/src/countries.ts](https://github.com/happykust/liteset/blob/main/superset-frontend/plugins/legacy-plugin-chart-country-map/src/countries.ts).
3. Установите зависимости фронтенда: `cd superset-frontend && npm install`.
4. Проверьте свою страну в Storybook плагинов: `npm run plugins:storybook`.
5. Соберите и установите Liteset из исходников.

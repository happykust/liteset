# Подключение к базам данных

Liteset не идёт с предустановленными драйверами БД. Главный шаг подключения Liteset к БД — **установить нужные драйверы** в окружение.

:::note
Вам понадобятся пакеты для БД метаданных и для всех источников данных, к которым вы будете подключаться через Liteset. Про настройку БД метаданных — см. [Docker Compose](/docs/installation/docker-compose), [Kubernetes](/docs/installation/kubernetes).
:::

:::info
Полный список БД-специфичных инструкций (около 40 движков с примерами connection-string'ов и нюансами) — в [англоязычной версии страницы](/docs/configuration/databases). Эта русская версия содержит обзорные таблицы и общие инструкции.
:::

Эта страница ссылается на драйверы для часто используемых движков.

## Установка драйверов БД

Liteset требует установленного Python [DB-API драйвера](https://peps.python.org/pep-0249/) и [SQLAlchemy-диалекта](https://docs.sqlalchemy.org/en/20/dialects/) для каждого движка, к которому вы подключаетесь.

Подробнее об установке новых драйверов в Liteset — см. [Установка драйверов в Docker-образах](#installing-drivers-in-docker-images).

Поддерживаются и другие БД — главный критерий — наличие функционального SQLAlchemy-диалекта и Python-драйвера. Поиск по ключевому слову `sqlalchemy + (имя бд)` обычно приводит к нужному.

Если вашей БД нет в списке, но у неё есть SQL-интерфейс — заведите [issue](https://github.com/happykust/liteset/issues), будем работать над поддержкой.

Чтобы написать собственный database connector для Liteset — см. [этот туториал](https://preset.io/blog/building-database-connector/).

### Установка драйверов в Docker-образах {#installing-drivers-in-docker-images}

Liteset требует Python-драйвер для каждого типа БД. Пример с MySQL — процесс одинаков для всех:

#### 1. Определите нужный драйвер

В [таблице выше](#supported-databases-and-dependencies) найдите PyPI-пакет (для MySQL — `mysqlclient`).

#### 2. Расширьте Docker-образ

Создайте `requirements-local.txt` рядом с docker-compose-файлом:

```bash
touch ./docker/requirements-local.txt
```

Добавьте в него драйвер:

```
mysqlclient
```

#### 3. Перезапустите Liteset

```bash
docker compose down
docker compose up
```

Драйверы установятся при следующей сборке образа.

#### 4. Подключите БД через UI

См. [Подключение через UI](#connecting-through-the-ui) ниже.

### Инструкции для конкретных БД {#database-specific-instructions}

Для каждой из ~40 поддерживаемых БД в Liteset есть индивидуальные особенности (генерация service-credentials в BigQuery, токены для Snowflake, sslmode для Postgres / Redshift, kerberos для Hive и т. д.). Полные пошаговые инструкции для каждой — см. [англоязычную версию](/docs/configuration/databases#database-specific-instructions). Базовая «формула» одинакова:

1. Установить драйвер из таблицы.
2. Получить credentials у владельца БД.
3. Сформировать connection string по примеру выше.
4. В Liteset UI: Settings → Database Connections → + Database, ввести URI, проверить Test Connection.

## Подключение через UI {#connecting-through-the-ui}

Краткий путь:

1. Settings → Database Connections.
2. **+ Database** в правом верхнем углу.
3. Выберите тип БД из списка.
4. В простом режиме введите host, port, database, username, password — Liteset сам соберёт URI.
5. В режиме SQLAlchemy URI введите готовую строку (см. примеры в таблице выше).
6. **Test Connection** — Liteset проверит подключение.
7. **Connect** — сохранит подключение.

После подключения база появится в **Sources → Databases**, и вы можете регистрировать таблицы как датасеты.

### Дополнительные настройки БД {#extra-database-settings}

В диалоге edit-БД на вкладке **Advanced** доступны параметры:

- **SQL Lab settings** — Expose in SQL Lab, Allow CREATE TABLE AS, Allow CREATE VIEW AS, Allow DML, Allow this database to be explored, Allow file uploads.
- **Performance** — Chart cache timeout, Schemas allowed for CSV upload, Asynchronous query execution.
- **Security** — Enable secure extra (encrypted JSON для credentials), Root certificate (для self-signed TLS), Impersonate logged in user, Allow dataset/file uploads.
- **Other** — Metadata cache timeout, Version, Engine Parameters.

Подробное описание каждого поля — в [англоязычной версии](/docs/configuration/databases#extra-database-settings).

## Misc

### Запросы между БД {#querying-across-databases}

Liteset поддерживает datasource-аналог cross-database queries через [shillelagh](https://github.com/betodealmeida/shillelagh) — драйвер, который умеет читать данные из других БД, REST API, CSV и Google Sheets через виртуальные таблицы. Используйте connection string `gsheets://`, `csv://` и т. п. См. [англоязычную версию](/docs/configuration/databases#querying-across-databases) для рецептов.

Сообщество

Liteset — академический порт. Сообщество небольшое, но upstream-сообщество Apache Superset большое и дружелюбное.

  • Репозиторий на GitHub

    Исходный код, релизы, инструкции для контрибьюторов и дипломный отчёт о тестировании.

  • Issues и запросы фич

    Сообщайте о регрессиях по сравнению с Apache Superset 6.0.0, запрашивайте новые возможности или берите задачу с тегом «good first issue».

  • Discussions

    Задавайте вопросы, делитесь опытом миграции и результатами бенчмарков.

  • Upstream — Apache Superset

    Liteset основан на Apache Superset 6.0.0 — большинство продуктовых вопросов и баг-репортов следует адресовать в upstream.

Ищете большое сообщество Superset — Slack, dev mailing list, ежемесячные митапы, тег на Stack Overflow? Они живут в upstream-проекте Apache Superset. Liteset переиспользует тот же продукт; продуктовые вопросы лучше задавать там.

Быстрый старт

Готовы попробовать Liteset? Этот гайд поможет поднять Liteset на локальной машине в три простых шага. Подразумевается, что у вас установлены Docker, Docker Compose и Git.

предупреждение

Несмотря на то что Docker Compose отлично подходит для быстрого старта в sandbox-окружении и для разработки, этот сетап не предназначен для продакшена. Для продакшена используйте установку на Kubernetes.

1. Получить Liteset​

git clone https://github.com/happykust/liteset

2. Запустить последний релиз​

# Перейдите в склонированный репозиторий
$ cd liteset

# Переключитесь на тег нужной версии
$ git checkout tags/6.0.0

# Поднимите Liteset через Docker Compose
$ docker compose -f docker-compose-image-tag.yml up

Это может занять некоторое время — Docker Compose скачает образы и подгрузит примеры. После того как все контейнеры будут скачаны и логи стабилизируются, можно входить.

⚠️ Если вы получаете ошибку вроде validating superset\docker-compose-image-tag.yml: services.superset-worker-beat.env_file.0 must be a string, обновите версию docker-compose. Обратите внимание: docker-compose устаревает, теперь следует использовать docker compose.

3. Войти в Liteset​

Откройте http://localhost:8088 и войдите со стандартными данными:

username: admin
password: admin

🎉 Готово! Liteset запущен на вашей машине! 🎉​

Завершение​

Когда закончите, остановите окружение как любой другой docker-стек:

docker compose down
подсказка

Окружение можно использовать многократно — Liteset сохраняет данные локально. Останавливайте процессы корректной командой Docker Compose stop, чтобы избежать повреждения и потери данных.
